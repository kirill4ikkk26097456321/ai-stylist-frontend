🚀 Инструкция по запуску AI Stylist Frontend
Этот проект представляет собой фронтенд-часть платформы ИИ-стилиста, построенную на Vite.

1. Подготовка окружения (macOS)

Если на компьютере еще не установлены инструменты разработки, выполни следующие шаги в терминале:

Установка Homebrew (если не установлен):

Bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
Установка Node.js через Homebrew:
Vite требует Node.js версии 18 или выше.

Bash
brew install node
2. Установка и инициализация проекта

Скачайте или клонируйте репозиторий с проектом.

Перейдите в папку проекта:

Bash
cd ai-stylist-frontend
Установите зависимости:

Bash
npm install
3. Запуск сервера разработки

Для запуска проекта в режиме реального времени (hot reload) выполните команду:

Bash
npm run dev
После запуска терминал выдаст ссылку (обычно http://localhost:5173). Открой её в браузере.

📂 Структура файлов проекта

Для удобства бэкенд-разработки стили разделены по логическим блокам в папке src/styles/:

global.css — базовые сбросы и общие стили.

variables.css — CSS-переменные (цвета, иконки в формате SVG Data URI).

auth.css — стили экранов входа и регистрации.

chat.css — верстка пузырей сообщений и интерактивных кнопок бота.

profile.css — стили личного кабинета и аккордеонов.

fitting.css — экран выбора вещей, фильтры и логика примерки.

sidebar.css — стили бокового меню истории чатов.

⚙️ Заметки для разработчика

Интерактивность: Вся логика переключения экранов, открытия аккордеонов и работы фильтров сосредоточена в src/main.js.

API Hooks: В main.js предусмотрены обработчики событий для кнопок отправки (ID: chat-send-btn) и перехода к примерке (ID: go-to-fitting-btn), куда можно интегрировать вызовы к API нейросети.

Тестовый флоу: Чтобы попасть на экран примерки из чата, дойдите до конца диалога и нажмите синюю кнопку «Подобрать образ».
